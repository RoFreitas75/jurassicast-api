# JCast / Jurassicast API

Primeira versão da API de filmes do Jurassicast.

## Endpoint

Depois de publicar na Vercel:

`/api/filme?titulo=tubarao`

Exemplo:

`https://SEU-PROJETO.vercel.app/api/filme?titulo=tubarao`

## Configuração

No painel da hospedagem, crie a variável de ambiente:

`TMDB_TOKEN`

Valor: seu token/API Read Access Token do TMDB.

Não coloque a chave diretamente no código e não publique a chave no GitHub.

## TMDB

Esta aplicação utiliza a API do The Movie Database (TMDB).

O uso da API deve respeitar os termos e as condições de licença do TMDB. Para projetos que usam os dados, siga também as exigências de atribuição do TMDB.
